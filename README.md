# ระบบสุ่มแบ่งสายกีฬาสี — TU Sport Day 2026

เว็บแอป **Static Site** (ไม่มี Backend) สำหรับสุ่มแบ่งนักกีฬาเข้า 4 สี — **ฟ้า ม่วง ชมพู เขียว** — ของงานกีฬาสีมหาวิทยาลัยธรรมศาสตร์
กรอกรายชื่อผ่านฟอร์ม Excel แล้วให้ระบบสุ่มแบ่งสีอย่างเป็นธรรม พร้อมจับสายแข่งขันรอบแรก (Seed 1) ให้อัตโนมัติ
การสุ่มและประมวลผลทั้งหมดทำงานด้วย JavaScript ในเบราว์เซอร์ ข้อมูลถูกเก็บไว้ในเครื่องผู้ใช้เท่านั้น (localStorage) ไม่ส่งไปที่ไหน

## เทคโนโลยี

- React + TypeScript + Vite
- Tailwind CSS
- SheetJS (`xlsx`) สำหรับอ่าน/สร้างไฟล์ Excel ฝั่งเบราว์เซอร์
- React Router (`HashRouter`) — ทำให้ deploy บน static hosting ได้โดยไม่ต้องตั้งค่า rewrite

## ประเภทกีฬาที่รองรับ (33 รายการ, ดูเฉพาะรอบซีดแรก)

1. เทนนิส — ทีมชาย/หญิงทั่วไป, ทีมชาย/หญิง 45+, เดี่ยว/คู่/คู่ผสมทุกรุ่น
2. ฟุตบอล — ทีมชาย แบ่งตามสีทีม
3. ฟุตซอล — ทีมชาย แบ่งตามสีทีม
4. วอลเลย์บอล — ทีมชาย/หญิง แบ่งตามสีทีม
5. บาสเกตบอล — ทีมชาย/หญิง แบ่งตามสีทีม
6. แบดมินตัน — คู่ชาย/หญิง/คู่ผสม รุ่นอายุ 20/40/50 ปีขึ้นไป
7. เปตอง — เดี่ยว/คู่/คู่ผสม/ทีม 3 คน ชาย-หญิง

ประเภท **แบ่งตามสีทีม** (ฟุตบอล ฟุตซอล วอลเลย์บอล บาสเกตบอล เทนนิสประเภททีม) จะสุ่มกระจายนักกีฬาทั้งหมดเข้า 4 สีเพื่อประกอบเป็นทีมของแต่ละสี แล้วสุ่มจับคู่แข่งรอบแรกระหว่าง 4 สี (2 คู่)

ประเภท **เดี่ยว/คู่/ทีม 3 คน** จะสุ่มแต่ละหน่วย (คน/คู่/ทีม) เข้าสีใดสีหนึ่งอย่างสมดุล แล้วสุ่มจับคู่แข่งรอบแรกระหว่างหน่วยด้วยกันเอง (พยายามเลี่ยงคู่แข่งสีเดียวกัน)

## เริ่มใช้งาน (โหมดพัฒนา)

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

## Build สำหรับ deploy

```bash
npm run build
```

ไฟล์ผลลัพธ์อยู่ในโฟลเดอร์ `dist/` — เป็น static site ล้วน ๆ นำไป host ที่ไหนก็ได้

## Deploy ฟรี

### Vercel

1. Push โปรเจกต์นี้ขึ้น GitHub
2. เข้า https://vercel.com/new แล้วเลือก repo นี้
3. Vercel จะตรวจพบ Vite อัตโนมัติ (Build Command: `npm run build`, Output Directory: `dist`) กด Deploy ได้เลย

### GitHub Pages

โปรเจกต์นี้มี GitHub Actions workflow ให้แล้ว ([.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)):

1. Push โปรเจกต์ขึ้น GitHub repo (branch `main`)
2. ไปที่ Settings → Pages → Build and deployment → Source เลือก **GitHub Actions**
3. Push โค้ดเข้า `main` อีกครั้ง (หรือรัน workflow เอง) ระบบจะ build และ deploy ให้อัตโนมัติ
4. เว็บไซต์จะอยู่ที่ `https://<username>.github.io/<repo-name>/`

## วิธีใช้งานระบบ

1. หน้าแรกกด **“ดาวน์โหลดฟอร์ม Excel (ทุกประเภท)”** จะได้ไฟล์เดียวที่มี 33 ชีต (1 ชีต/ประเภทกีฬา)
2. กรอกรายชื่อนักกีฬาลงในแต่ละชีตตามหัวคอลัมน์ที่กำหนด (ไม่ต้องแก้ไขหัวตาราง/ชื่อชีต)
3. อัปโหลดไฟล์เดิมกลับที่ปุ่ม **“อัปโหลดไฟล์รวม”** — ระบบจะกระจายข้อมูลเข้าแต่ละประเภทกีฬาให้อัตโนมัติ
   - หรือจะเข้าไปอัปโหลด/พิมพ์รายชื่อเองทีละประเภทในหน้ารายละเอียดก็ได้
4. เข้าไปที่แต่ละประเภทกีฬา กด **“สุ่มแบ่งสี”** — ระบบจะสุ่มแบ่งอย่างเป็นธรรม (จำนวนแต่ละสีต่างกันไม่เกิน 1) พร้อมจับสายแข่งรอบแรก (Seed 1) ให้ทันที
5. ส่งออกผลเป็น Excel ได้ทั้งรายประเภท (ปุ่มในหน้าประเภทกีฬา) และสรุปรวมทุกประเภท (หน้า “สรุปผล & ส่งออก”)

ข้อมูลทั้งหมดถูกบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์ที่ใช้งาน — ถ้าต้องการใช้งานต่อจากเครื่อง/เบราว์เซอร์อื่น ให้ส่งออกไฟล์ Excel แล้วอัปโหลดเข้าเครื่องนั้นแทน
